## Scope

This repository is intentionally small. It is not an impressum generator, legal template or compliance product. It only publishes the provider and contact notice for Lukas Geiger's public GitHub and Um:bruch-related work.

## For Reuse

Use this repository as a stable reference when linking from:

- GitHub organization profiles and project READMEs
- research, publication and open-data pages
- public profile pages that require a German legal notice
- crawler or LLM context files that need a canonical legal-contact target
